# ROM Files

Retro64 includes built-in open-source ROM replacements and works out of the box.

For maximum compatibility, you can place original Commodore 64 ROM images here:

- `kernal` — 8192 bytes, KERNAL ROM
- `basic` — 8192 bytes, BASIC V2 ROM
- `chargen` — 4096 bytes, Character Generator ROM

Then run with: `retro64 --rom-dir ./roms`

ROM images can be extracted from real C64 hardware or found in VICE's rom directory.
